# 이미 상자 안에 있는 것 — ST 이미지 재고

> 살아 있는 참조 — **이미 상자 안에 있는 것. 커널을 쓰기 전에 여기부터 본다.** 여기가 틀리면 그건 버그다.

`engine/kernels/SOURCES.json` 은 **무엇을 들여왔는지**를 적는다. **무엇이 이미 있는지**는 아무 데도 안 적혀 있었고,
2026-09-12 그게 하루를 먹었다 — 정렬 없는 top-k/top-p 샘플러 커널(Triton 249줄)을 손으로 써서 머지한 뒤에야
`flashinfer.sampling.top_k_top_p_sampling_from_probs` 가 이미 이미지 안에 있고 **1.4~1.8× 빠르다**는 걸 알았다.

**커널을 한 줄 쓰기 전에 여기를 본다.** 목록은 실물에서 다시 뽑을 수 있다:

```bash
python3 tools/inventory.py --grep rmsnorm      # 이름으로 찾기
python3 tools/inventory.py --write             # 아래 생성 블록 갱신
```

## 우리가 손으로 쓴 자리와 겹치는 것 (확인된 것만)

| 우리 코드 | 이미지 안에 있는 것 | 상태 |
|---|---|---|
| `engine/kernels/sampler.py` | `flashinfer.sampling.top_k_top_p_sampling_from_probs`, `top_p_renorm_probs`, `top_k_mask_logits` | **실측 1.4~1.8× 빠름**, 정확도 무승부. `engine/TRTLLM_COMPARISON_20260912.md` §1.1 |
| `base/sampler.block_verify_batch` | `flashinfer.sampling.chain_speculative_sampling` | 같은 자리. 미대조 |
| 구조화 출력 비트마스크 (45차 §31) | `xgrammar.allocate_token_bitmask`, `apply_token_bitmask_inplace`, `BatchGrammarMatcher` | **미대조** — 우리 쪽이 스텝 하나에 맞춰져 있으나 배치 매처는 안 봤다 |
| b12x MoE 레인 | `flashinfer.fused_moe.B12xMoEWrapper`, `B12xNvfp4Runner`, `B12xW4A16Runner` | **미대조** — 이름이 우리 커널과 같다 |
| KDA/MLA o_norm, qk-norm | `flashinfer.norm.fused_add_rmsnorm`, `fused_qk_rmsnorm_rope`, `fused_rmsnorm_silu` | **미대조** |
| NVFP4 KV append | `flashinfer.page.nvfp4_quantize_append_paged_kv_cache_with_slot_mapping` | **미대조** |

**"미대조" 는 "안 쓴다" 가 아니라 "아직 재 보지 않았다" 다.** 대조할 때의 규칙(TRT-LLM 대조에서 배운 것):
상한은 **우리 것과 같은 실행 안에서** 재고, **CUDA 그래프 캡처 가능 여부**와 **행별 텐서 인자**를 같이 확인한다 —
그 둘이 채택을 막는 흔한 이유다.

## 없는 것 (확인함)

`outlines`, `flash_attn` — 이미지에 없다. 필요하면 들여오는 비용부터 센다.
