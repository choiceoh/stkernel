## 0919c (µs/호출, 최소)

| 단계 | 512 행 | 4,096 행 |
|---|---:|---:|
| 라우터 MMA [512] (#1300) | 101.3 | 245.8 |
| 라우팅 `moe_route.softmax_topk` (서빙, 이미 main) | 69.6 | 131.5 |
| 라우팅 torch softmax + topk (참조) | 151.5 | 484.2 |
| 공유 게이트 mm [1] + sigmoid | 99.6 | 141.9 |
| **재매핑 + 마스크 + nonzero (전)** | 417.9 | 413.6 |
| **`compact_routes` + nonzero (후)** | **161.1** | **169.9** |
| **모으기: x 행 + id + 가중치 (전)** | 121.4 | 345.0 |
| **`pair_rows` (후)** | **73.9** | 349.6 |
| `pair_sum` | 74.2 | 412.7 |

- 쌍 수: 512 행 1,223, 4,096 행 10,199. 두 새 발사 모두 전과 **바이트 동일**(`compact_routes_bytes`, `pair_rows_bytes`).
- 4,096 행 모으기는 x 행 52 MB 를 쓰고 읽는 대역폭이 한계라 비김. 512 행에서는 발사 수가 줄어 −47 µs.
- 라우팅은 main 이 이미 서빙 커널(`softmax_topk`)을 쓴다 — 참조(torch) 대비 −353 µs 는 이미 받은 몫.

추정(측정 아님): 층마다 4,096 행 약 −0.24 ms, 512 행 약 −0.30 ms → 4,096 토큰 청크(MoE 49 층)에서 약 −12 ms. 플릿 onepass 미측정.
