  턴 · 도구 결과 · 시스템 프롬프트 · **다른 모델이 쓴 답**이었다. 다음 창은 모델이 직접 답한 글의 답 구간만 배운다(#1301).

  나눠 넣어 평가 창의 글 대부분을 헤드가 학습 때 봤다. ② 자리: 헤드는 서빙에서 모델 자신의 답 안에서만 드래프트한다. Deneb 프리필의

  라이브 디코드가 가지 않는 자리의 실력이다. v2 합성 대화의 답은 서빙 모델 자신이 서빙 설정으로 쓴 글이라 맞는 종류지만, 헤드가 원래
  강한 곳이라 느는 폭이 작다(+0.7~1.2%).
- 팔끼리 디코드한 텍스트가 거의 다르다(같은 텍스트 19/180) — 창 3 과 같이, 짝은 같은 프롬프트 위의 비슷한 텍스트 비교다.
