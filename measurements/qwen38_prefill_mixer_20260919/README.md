## 2. 다운 + 게이트 (µs/사이트, 최솟값)

| 행 | cuBLAS + `_gates` (0919d) | 정규화된 스트림 위 최속 (0919d) | 스트림을 안에서 정규화, 표 (0919norm) |
|---:|---:|---:|---:|
| 512 | 86.1 | 101.9 (64·128·64·4·3·2) | 145.5 (64·128·64·4·3·2) |
| 1,024 | 167.9 | 163.6 (128·64·64·4·3·1) | 205.8 (64·128·64·4·3·2) |
| 2,048 | 297.5 | 268.0 (128·128·64·8·3·1) | 374.7 (256·64·64·8·3·1) |
| 4,096 | 584.0 | 531.7 (128·128·64·8·3·1) | 776.1 (256·64·64·8·3·1) |

- 새 다운 커널: 한 행 블록의 열 블록이 이웃 프로그램(행을 DRAM 에서 한 번), 주입 4 열은 16 폭 꼬리 블록, 행이 적으면 K 분할(마지막 프로그램이 분할 순서대로 합침).
- 4,096 행 다운은 MMA 가 한계: 27.2 GFLOP(384 열로 패딩)에 약 51 TFLOPS.
- **안에서 정규화하는 값**: A 타일 원소마다 fp32 곱 둘과 변환 둘을 열 블록 프로그램마다 되풀이 — MMA 와 같은 차수의 시간. 128·128·64 는 567 → 849 µs,
  256·64·64 는 570 → 776. 업 접기는 +8%. 한 CTA 가 324 열 전부를 맡으면 변환이 한 번으로 준다 — 다음 레버.

커널 곱의 차이(최대 0.006, 2,048·4,096 행에서 0).
