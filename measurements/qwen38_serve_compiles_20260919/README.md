- **"처음 쓰인" 의 뜻:** Triton 과 b12x 게터는 디스크 캐시에서 읽어 온 커널도 같은 프로세스 캐시에 넣는다. 레인의 디스크 캐시는 실행을 넘어
  남으므로 여기서 밀리초로 읽힌 것도 새 트리의 첫 부팅이면 컴파일이다. 목록이 "문 뒤에서 무엇이 만들어지나"이고, 시간은 이 실행의 것이다.
- 첫 디코드 스텝 1.10 s 말고는 모든 디코드 스텝이 16 ms 이하(작은 net 의 값) — 요청 중 느린 스텝은 전부 이 목록에서 나왔다.
- 층 두 개짜리 net 이다: 48 층 랭크는 같은 모양의 층을 되풀이하므로 같은 커널을 쓰고 더 쓰지 않는다. 속도 주장 없음(D17).
