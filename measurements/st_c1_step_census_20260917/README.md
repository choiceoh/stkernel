## 안 잰 것

- **속도 판정 아님.** CUPTI 합이고 C=1 step/s 채널이 아니다(규칙 2). 이 표의 절대값으로 개선을 주장할 수 없다.
- **통신 칸의 절대값은 못 믿는다.** `k_oneshot` 이 3.8발에 2,973 µs(발당 782 µs)로 찍히는데, 같은 부팅의
  배치 이벤트는 8행 31.7~33.2 µs 를 말한다(`stkernel-oneshot-comm-wait`). PDL 겹침이 합산됐다. 10.6% 는 상한이다.
- **공유 전문가를 분리 못 한다.** MoE 라우팅 커널 안에 융합돼 있어 별도 커널로 안 보인다. 원장이 지목한
  "라우팅 커널 안의 공유 전문가(W4A4)" 는 이 방법으로는 확인도 반박도 안 된다.
- **C=2 없음.** 한 폭만 쟀다. 폭 배수는 `st_concurrency_width_20260916` 이 갖고 있다.
- **rank 0 만.** 랭크는 대칭이고 문이 말하는 것은 rank 0 이다.
- **한 번.** 반복 없음. 런치 수는 결정적이지만 µs 는 요청 하나의 무늬를 탄다.
